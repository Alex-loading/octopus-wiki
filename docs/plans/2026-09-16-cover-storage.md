## 数据与权限

保留 `cover_url` 原链接，新增 `cover_storage_path` 保存内容哈希文件名。数据库不持久化临时签名 URL。图片内容不重新编码；支持 JPG、PNG、WebP、GIF、AVIF，下载上限 8 MiB。

所有对象保存在私有桶。浏览器使用 Supabase 客户端下载，Storage RLS 根据关联收藏的既有权限判定：公开收藏箱中的公开收藏可匿名读取，私有收藏仅管理员可读取。未关联的对象不开放读取。图片清除、收藏删除不自动删除存储对象，以便恢复。

已有存储路径且封面链接未改变时，编辑标题或备注直接复用图片。新图片下载失败时保留表单并提示更换或清空封面，不静默退回临时外链。服务端校验重定向、DNS、公网 IP、格式和大小，并固定连接已校验 IP，避免内网访问和 DNS 重绑定。

## 历史封面恢复

旧小红书图片返回 403。原预览请求头得到的页面只带平台默认图，但普通桌面请求能得到真实笔记及新的签名图片。预览器现对小红书使用桌面请求头，保留原分享参数，同时拒绝把平台默认图当成资源封面。此次恢复了全部旧封面，包括一条以前误存默认图的记录。

本机 DNS 代理对公网域名返回 `198.18/15` 合成地址。下载器遇到这一范围时使用固定 Cloudflare HTTPS DNS 查询真实地址，之后仍执行公网校验并固定连接；不会放行内网地址。

## 运维

```bash
nvm use
npm run dev

# 默认只读预检；--apply 才上传并修改存储路径
npm run covers:backfill -- --report /tmp/cover-preview.json
npm run covers:backfill -- --apply --report /tmp/cover-migration.json
```

迁移脚本自动加载 `.env.local`，跳过已有路径与无封面记录；按内容哈希去重，以 `updated_at` 和旧封面值做条件更新，避免覆盖同时发生的编辑。无法恢复的记录保持原样并写入报告。

生产部署需要包含新 `/api/bookmarks`、更新后的 `/api/collector` 和前端代码。`vercel.json` 已配置保存接口的运行时长与 Chromium 文件；现有 Supabase 和飞书服务端凭据继续使用，无新增密钥。
