# 像素小屋首页

## 已确认需求
- 参考 https://www.douyin.com/video/7684842495410301937 的斜俯视暖光卧室。
- Blender 搭建可编辑室内场景；像素风渲染；人物可走动并触发分类内容。
- 首页默认小屋，提供传统列表切换（用户已确认）。

## 实现
- Blender Python 脚本生成木地板、两面墙、窗户、床、电脑桌、书架、收藏柜、植物和人物；保存 .blend 并导出 GLB。
- Three.js 正交相机、低分辨率画布、最近邻放大、夜景和暖灯；GLB 按需加载。
- WASD/方向键、触屏方向键、点击地面寻路；使用同一布局元数据定义家具碰撞、角色出生点和触发区域。
- 书架：文章，可按已有分类筛选；工作台：真实妙妙屋项目；收藏柜：公开收藏夹；床边：关于。
- 靠近显示提示，E/Enter 或按钮打开面板。点击区域标签可自动走到该区域并打开内容。
- 面板使用可访问 Dialog，打开时暂停人物操作；关闭恢复焦点。
- 本地记录首页模式；WebGL/模型失败提供重试和传统列表；移动端使用响应式画布。
