# 微信公众号收藏与剪贴板识别

## 目标

收藏入口用一次点击完成读取剪贴板、解析分享文案、识别平台和读取标题封面。新增微信公众号文章平台，首期只支持 `https://mp.weixin.qq.com/...` 的公开文章，不抓取正文，不依赖微信登录或 Cookie。

## 交互

按钮文案改为「读取剪贴板并识别信息」，没有链接时也可点击。读取到唯一链接后，将剪贴板原文写入「链接或分享文案」，识别平台并立即请求标题和封面。多个链接继续展示选择框，不自动猜测；无链接时提示用户复制文章链接。浏览器拒绝剪贴板权限时，继续识别表单中已手工粘贴的内容，避免破坏原有流程。手工编辑过的标题仍不会被预览覆盖。

## 数据与服务端

新增 `wechat` 平台类型和数据库约束迁移。预览白名单只加入精确主机 `mp.weixin.qq.com`，阻止相似恶意域名；公众号对非浏览器请求头返回验证页，因此服务端使用与小红书相同的桌面浏览器请求头。标题和封面继续从 Open Graph/Twitter 元数据读取，封面由现有私有 Supabase Storage 流程转存。

## 验证

覆盖平台识别、白名单、桌面请求头、微信 Open Graph 元数据、剪贴板一键填充、数据库约束迁移、旧的手工粘贴回退和完整构建。另用用户提供的文章真实请求核对标题「我不得不把才华埋葬在昨天」及 `mmbiz.qpic.cn` 封面。
